Support policy

Support is included with Glowcore. This page explains what it covers, so you know what to expect.

What support covers

  • Theme setup: help installing Glowcore and setting up its sections, blocks and menus.
  • Theme settings: explaining what a setting does and how to get the result you want with the existing settings.
  • Bugs: fixing problems in Glowcore's own code, such as a broken layout, a dead link or a feature that doesn't work as documented. We fix critical bugs as soon as possible.
  • Questions about how Glowcore works with Shopify features, such as Markets, filters, swatches and customer accounts.

What support doesn't cover

  • Custom code changes: changes to the theme code, new features or design changes beyond the theme settings, and problems caused by code you or someone else added, including code in Custom Liquid sections and blocks.
  • Third-party apps: setting up, styling or fixing apps. Contact the app developer for help with their app. We'll still confirm that Glowcore's own app blocks and sections work as expected.
  • Store design work: designing your store, writing content, editing images or setting up products, collections or your demo content.
  • Shopify features outside the theme: checkout, payments, shipping rates, domains and your Shopify plan. Contact Shopify Support for these.

Before editing theme code: duplicate your theme in Online Store > Themes first, so you can go back if something breaks. For custom code work, we recommend hiring a Shopify Partner.

Response time

We reply to every support request within 2 business days. Support hours are Monday to Friday, 10:00 to 18:00 Europe/Sofia time (EET/EEST), with no support on Bulgarian public holidays. See Support for how to contact us.

Updates

  • Theme updates are free. They're released through the Shopify Theme Store and include bug fixes, improvements and changes needed to keep up with Shopify.
  • Shopify shows you when an update is available in Online Store > Themes. You decide when to install it. See How do I update Glowcore?
  • Settings and content you set in the theme editor are kept when you update. Custom code changes aren't, so keep a copy of them.
  • Every release is listed in the changelog.
  • We support the latest version of Glowcore. If you report a bug that's already fixed, we'll ask you to update first.
